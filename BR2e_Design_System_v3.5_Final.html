Typography

Font availability: The OUP fonts (PalatinoLTStd, NewsGothicMTStd, CaeciliaLTStd) are commercial fonts requiring a licence. This guide renders using the closest freely available Google Fonts alternatives:
• Body text — Lora (Google Fonts) substitutes for Palatino LT Std. A refined serif with similar old-style character proportions.
• Headings/labels — Barlow Condensed (Google Fonts) substitutes for News Gothic MT Std. A geometric condensed sans with similar weight and rhythm.
• Talking Point title — Rokkitt (Google Fonts) substitutes for Caecilia LT Std. A humanist slab serif.
For Word and PowerPoint: install these fonts from fonts.google.com and use them in your styles. They are free for all uses including commercial.
Critical correction from v1 & v2: All three font families are now confirmed from the PDF fontname field. The body is Palatino (serif), not Helvetica. Headings are News Gothic (sans), not Helvetica. The Talking Point title is Caecilia (slab serif). The OCR of scanned PDFs returned 'Helvetica' as a generic fallback — unreliable for font identification.

Colour Families — Structure & Derivation

The PDF uses four colour families. Only Family C (the level accent) changes between levels. Families A, B and D use identical hex values in every level. This means a single template needs only one variable swapped to produce any level's colour scheme.

Family C — Level Accent (swap per level)

Three colour representations per level:
  • CMYK — exact values from the vector PDF. Authoritative for print production.
  • Naive sRGB — mathematical conversion (1−C)(1−K) formula. Use this in Word, PowerPoint, CSS for digital/screen work. This is what the guide swatches render.
  • Print-rendered — pixel-sampled from the OUP PDF displayed on an iPhone (iOS PDF engine with ICC colour management). This is how the colour actually appears in the printed book — darker and less saturated. Use as a reference when trying to visually match the physical book.
Also included: card tint — the light background colour of each level card on page 16, pixel-sampled from the same iPhone screenshot. Not present as a vector element — these come from the photographic page background.
Family C is the only colour that changes between levels. It is used in exactly two places: the accent band and the 2mm stripe on the unit number block. No tint scale is used in unit pages — only one tint (#E5D37C for Intermediate) appears as a minor cover decoration. All other UI colours remain constant.

Creating Your Own Colour Style Sets

This section explains how the Business Result colour system works in practical terms — and how you can use it as a model to build style sets for your own materials that feel coherent, professional and flexible across multiple document types or levels.

How the BR system is built (the short version)

The whole series uses one accent colour per level, and everything else stays the same. The teal UI, the amber outcomes, the crimson crossrefs — none of those change between Starter and Advanced. Only the one accent slot changes. This is why all six books feel like a family even though they're visually distinct.

Within the teal and amber families, OUP didn't pick random tints — they stepped saturation down while keeping hue and brightness roughly constant. This is what makes the light blue table rows feel like they "belong" with the dark teal column headers, without clashing.

You can use exactly the same approach: pick one accent colour per "level" or "subject" or "document type", then build a small family of tints from two fixed UI colours.

The BR colour set recipe

RoleHow to choose itBR example
Accent (1 per level)Pick a distinctive colour. High saturation, medium-dark value. Avoid anything too close to your UI colours.#D1A624 (Intermediate screen — screen hex)
UI dark (headers, rules)Pick one consistent colour for all structural elements across every level. Medium-dark, clearly readable on white.#0097B2 (teal)
UI tints × 5Take the UI dark colour, keep the hue, step saturation down: 100% → 47% → 30% → 20% → 13% → 10%. These become your rules, row backgrounds, box fills.#0097B2 → #72BFD8 → #A2DDE8 → #BFE8EF → #D4EBF3 → #DEF3F7
Highlight (outcomes/callouts)A warm contrasting colour — amber, orange, or yellow. Used for the element that needs to stand out most.#FFA526 (amber)
Highlight tints × 4Same approach: step the highlight saturation down for background fills.#FFA526 → #FFC97C → #FFD292 → #FFE4BD → #FFE8C8
Action colourA high-contrast colour for interactive/attention elements (crossrefs, titles). Often crimson, purple or deep red.#CC0051 (crimson)
