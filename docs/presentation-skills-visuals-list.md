# Presentation Skills — Visuals List (Pre-Stage 3)

Status: draft, for review before image generation begins.
Purpose: catalogue every visual asset the three manuscripts (Essentials/Standard/Long) would
benefit from, so Stage 3 layout work has a concrete image list to build against rather than
discovering gaps mid-build.

Each entry has: **Unit**, **Type** (diagram / process illustration / scenario photo / table-as-graphic),
**Tiers needed** (some visuals only make sense where the unit exists), a **description** of what
the image should show, and a **generation prompt** draft for the OpenAI image tool.

Diagrams should be built as clean, textbook-style vector-flat illustrations — consistent style
across the whole book matters more than any single image being flashy. Scenario photos should be
generic/non-identifiable (no named-likeness), stock-photo-style, diverse, professional context.

---

## Cross-cutting style note (read before generating anything)

Before generating individual images, it's worth fixing one consistent visual style guide across
the whole book, the same way the text has per-tier voice guides. Recommend generating 2-3 test
images first (e.g. the Logic Tree diagram and one appendix scenario photo) to lock in:
- A consistent illustration style for diagrams (flat vector / line-art, consistent color palette)
- A consistent photo style for scenario images (same "warmth," same level of realism, same aspect ratio)
- Whether diagrams carry the book's own terminology as embedded labels (recommended) or stay label-free
  for localization flexibility

## Unit 1 — Why Presentations Matter

### 1.1 The 6 Keys diagram
- **Type:** Diagram
- **Tiers:** All three (Essentials/Standard/Long) — this is the book's most foundational framework
- **Description:** A clean hexagonal or wheel diagram showing the 6 Keys (Purpose, Content,
  Structure, Language, Delivery, Visual Aids) as six equal segments around a center, implying
  "all six matter equally, check all six." Avoid implying a sequence/order, since the unit text
  is explicit that this is a diagnostic checklist, not a linear process.
- **Generation prompt draft:** "A clean, modern flat-vector infographic diagram showing six equal
  segments arranged in a circle around a central hub, each segment labeled with one word: Purpose,
  Content, Structure, Language, Delivery, Visual Aids. Professional textbook illustration style,
  muted professional color palette (blues, grays, one accent color), no photographic elements,
  plenty of white space, simple line icons per segment (target for Purpose, document for Content,
  building blocks for Structure, speech bubble for Language, person speaking for Delivery, slide/chart
  for Visual Aids)."

### 1.2 In-person vs. online audience comparison
- **Type:** Diagram / split illustration
- **Tiers:** All three
- **Description:** A simple side-by-side split image: left half shows a presenter reading an
  engaged in-person audience's body language (attentive posture, eye contact); right half shows
  the same presenter on a video call grid with muted cameras, divided attention, notification
  pop-ups. Supports the unit's point that online changes Purpose/audience analysis.
- **Generation prompt draft:** "A clean flat-vector split illustration, left side showing a
  presenter speaking to a small engaged in-person audience with visible attentive body language,
  right side showing the same presenter on a laptop video call with a grid of muted/distracted
  participant tiles and a notification icon. Professional textbook illustration style, consistent
  muted color palette, no text labels except a thin center divider line."

## Unit 2 — Structure of a Speech (+ Theme vs. Message)

### 2.1 Introduction/Body/Conclusion structure diagram
- **Type:** Diagram
- **Tiers:** All three
- **Description:** A simple three-part horizontal flow diagram: Introduction → Body → Conclusion,
  with a small callout showing the "say what you'll say / say it / say what you said" loop —
  perhaps an arrow curving back from Conclusion to Introduction to show the message is restated at
  both ends.
- **Generation prompt draft:** "A clean flat-vector horizontal flow diagram with three connected
  boxes labeled Introduction, Body, and Conclusion, left to right, connected by arrows. A subtle
  curved dashed arrow loops from the Conclusion box back to the Introduction box, suggesting an
  echo of the same message. Professional textbook illustration style, muted color palette."

### 2.2 Theme vs. Message contrast graphic
- **Type:** Diagram
- **Tiers:** All three
- **Description:** A simple two-column comparison graphic: "Theme" (a plain label icon, neutral)
  vs. "Message" (a label with a small "for/against" or thumbs-up/down icon suggesting something
  arguable). Reinforces the "could someone disagree with it?" test.
- **Generation prompt draft:** "A clean flat-vector two-panel comparison graphic. Left panel
  labeled 'Theme' shows a plain gray tag icon. Right panel labeled 'Message' shows a tag icon with
  a small pair of opposing arrows or a debate/disagreement icon next to it, in an accent color.
  Professional textbook illustration style, minimal, no photographic elements."

## Unit 5 — The Logic Tree

### 5.1 The Logic Tree diagram (core framework visual — highest priority in the book)
- **Type:** Diagram
- **Tiers:** All three
- **Description:** This is arguably the single most important diagram in the entire book. A
  literal tree diagram with five labeled parts, bottom to top: Roots (underground, prep/research),
  Trunk (the single vertical trunk, theme), Branches (3 branches emerging from the trunk, main
  points), Leaves (clustered on each branch, supporting details), Fruit (hanging from the branches
  or at the top, the takeaway/message). This should visually mirror the text's own "Roots feed the
  Trunk, Trunk grows Branches..." framing.
- **Generation prompt draft:** "A clean flat-vector illustration of a simple stylized tree used as
  an educational diagram, with five clearly labeled parts from bottom to top: 'ROOTS' (visible
  root system below a ground line), 'TRUNK' (single central trunk), 'BRANCHES' (exactly three
  branches splitting from the trunk), 'LEAVES' (clustered on each branch), and 'FRUIT' (a few
  pieces of fruit hanging among the leaves). Professional textbook infographic style, muted natural
  color palette (browns, greens), clean label callout lines, plenty of white space, no photographic
  texture."

### 5.2 Populated worked-example tree (the budgeting-app example)
- **Type:** Diagram (same tree template as 5.1, but filled in)
- **Tiers:** All three
- **Description:** The same tree diagram template as 5.1, but with the budgeting-app worked
  example's actual content filled into each part (Roots: audience/purpose notes; Trunk: "This app
  gives you your evenings back"; 3 Branches: Fast/Accurate/Affordable; Leaves: the specific proof
  points; Fruit: the call to action). This gives Stage 3 a ready-made "filled-in" version to place
  right after the blank template, reducing layout guesswork.
- **Generation prompt draft:** "Using the same tree diagram template and style as the blank Logic
  Tree diagram, populate it with short text labels: Trunk reads 'This app gives you your evenings
  back'; three branches read 'Fast,' 'Accurate,' 'Affordable'; small leaf labels under each branch
  show one supporting detail each; the fruit is labeled '30-day free trial.' Same flat-vector
  educational diagram style, muted natural palette, clean and legible at small size."

## Unit 6 — Slide Design (Visual Aids)

### 6.1 Rule of 1 / Rule of 7 comparison graphic
- **Type:** Diagram (side-by-side slide mockups)
- **Tiers:** All three
- **Description:** A "before/after" pair of mock slide thumbnails: one dense, cluttered slide
  (violating Rule of 1 and Rule of 7 — multiple ideas, too many lines/words) next to one clean
  slide (one idea, well within the Rule of 7 limits). This is one of the most useful visuals in
  the book since it makes an abstract rule immediately concrete.
- **Generation prompt draft:** "A side-by-side comparison of two mock presentation slide
  thumbnails in a clean flat-vector illustration style. Left slide, labeled 'Before,' is visually
  dense with many small lines of placeholder text/lorem-ipsum-style scribble lines and a cluttered
  layout. Right slide, labeled 'After,' shows one large clear headline placeholder and a single
  simple icon or chart, with generous white space. Professional textbook style, muted colors, no
  real readable text needed — abstract scribble lines are fine for the dense slide."

### 6.2 Four-part deck structure diagram
- **Type:** Diagram
- **Tiers:** All three
- **Description:** A simple horizontal sequence of four mock slide thumbnails labeled Title,
  Index, Content, Conclusion, showing the standard deck shape the unit teaches.
- **Generation prompt draft:** "A clean flat-vector horizontal row of four simple mock slide
  thumbnails connected by arrows, labeled in order: Title, Index, Content, Conclusion. Each
  thumbnail shows a distinct simple abstract layout suggesting its function (Title: centered large
  text block; Index: a short vertical list; Content: a chart/body layout; Conclusion: one bold
  centered statement). Professional textbook illustration style, muted palette."

### 6.3 Colorblind-safe contrast illustration
- **Type:** Diagram (educational comparison)
- **Tiers:** All three
- **Description:** A side-by-side or overlay graphic showing a red/green chart or slide element as
  seen by someone with typical vision vs. the same element as seen by someone with red-green color
  vision deficiency (where the red and green become indistinguishable), reinforcing the unit's
  accessibility guidance.
- **Generation prompt draft:** "An educational side-by-side comparison graphic showing the same
  simple bar chart or slide element twice: left labeled 'Typical vision' with clearly distinct red
  and green bars, right labeled 'Color vision deficiency (simulated)' showing the same chart with
  the red and green bars appearing nearly identical brownish-gray tones. Clean, professional,
  factual illustration style, not alarming, small explanatory framing."
