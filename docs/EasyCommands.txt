Textmaker quick commands
========================

Run these from the repository or project folder that owns the input/output paths.


Administrative Writing INT DOCX
-------------------------------

textmaker.cmd markdown-to-docx `
  --input int\md\working\aw-int-all_0519.md `
  --reference adv\md\working\aw-adv-styleref.docx `
  --lua-filter ..\textmaker\scripts\style_bridge.lua `
  --output int\md\working\aw-int-all_0530.docx `
  --no-pagebreak-filter `
  --apply-semantic-labels `
  --tag-style outline

DOCX to PDF
-----------

textmaker.cmd docx-to-pdf `
  --input  "..\book_administrative-writing\int\md\working\aw-int-all_0530.docx" `
  --output "..\book_administrative-writing\int\md\working\aw-int-all_0530.pdf"


Generic Markdown to DOCX
------------------------

textmaker.cmd markdown-to-docx `
  --input <file-or-folder> `
  --reference reference.docx `
  --lua-filter scripts\style_bridge.lua `
  --output output.docx `
  --apply-semantic-labels


Useful optional flags
---------------------

--profile
Print timing information for Markdown normalization, Pandoc, and DOCX postprocess passes.

--progress-warn-seconds 30
Print a still-running warning after this many seconds for each stage. Use 0 to disable warnings.

--tag-style outline
Use outline semantic tag icons instead of the default filled icons.
