# Facilitation Skills for International Meetings (AS Online) - Unit Files

This folder contains the unit-level DOCX files split from `Facilitation Skills for International Meetings (AS Online).docx`.
Each unit lives in its own subfolder and the DOCX is image-free.

These unit files are generated artifacts and are not committed to the repository to avoid
binary-file limitations in pull requests. Use `scripts/split_docx_units.py` to regenerate
them locally.

## Regenerate
```bash
python scripts/split_docx_units.py \
  "Samples/Meetings/Facilitation Skills for International Meetings (AS Online).docx" \
  "Samples/Meetings/Facilitation Skills for International Meetings (AS Online) units"
```
