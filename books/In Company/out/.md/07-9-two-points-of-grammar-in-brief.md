# 9. Two Points of Grammar in Brief

At first

Avoid using “At first”. Although it is grammatically correct it is misunderstood and it is almost always used incorrectly.

“At first” is not a counter -

Count: 1, 2, 3 or First, second, third…

“At first” introduces a condition that is going to change. For example:

*When I started work, <u>at first</u> everything was difficult because everything was new. <u>However</u>, as I continued to work everything got easier.*

Agree - with, on /about, to, that

Samples

|  |
|----|
| I agree <u>with</u> you. - Same thinking. |
| I agree <u>with</u> your comments. - Same thinking. |
| We agree <u>on/about</u> the need for more research. - Same thinking + noun. |
| We agreed <u>that</u> we had to do more research. - Same thinking + action. |
| I agree <u>with</u> honest business practices. - Think a principle or an idea is right. |
| We agreed <u>on</u> the agenda. - Decision. |
| I agree <u>to</u> your proposal. - Accept. |
| Our client finally agreed <u>to</u> the design. - Accept. |
| Mr. Suzuki agreed <u>to</u> present a report at the next meeting. - Accepting a requested action. |
| This food doesn’t agree with me. - Makes me sick. |
