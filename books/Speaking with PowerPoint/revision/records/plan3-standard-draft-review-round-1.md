## Returned Findings

### Agent 2: Language Editor

Read-only review completed. No files edited.

Overall judgment:

- No blocking critical issue from the Language Editor role.
- The 12 Standard unit drafts are broadly aligned with the B1-B2 ESL purpose, learner-owned English policy, Standard voice, and explicit presentation-English syllabus.
- The drafts should not move to layout/final production before the language and pedagogy repairs below are made.

Important improvements:

1. Normalize Standard voice and heading conventions across all units.
   - Units 1-3 use Title Case section headings, while Units 4-12 mostly use sentence-style headings.
   - Recommended fix: use sentence-style headings across the Standard draft set unless a later production style overrides this.

2. Define recurring specialist terms earlier and more consistently.
   - Terms needing first-use support include `pre-read`, `leave-behind`, `fallback`, `async`, `storyboard`, `sanitized`, `accessibility`, and `confidentiality`.
   - Recommended fix: add short learner-facing definitions or parenthetical glosses at first use.

3. Add a stronger pronunciation/intelligibility spiral before Unit 8.
   - Unit 8 and Unit 11 handle pronunciation/intelligibility well, but earlier spoken tasks mostly focus on content rather than sound.
   - Recommended fix: add short "say it clearly" micro-tasks in Units 2, 4, 5, 6, and 10.

4. Add Japanese-learner notes where they solve concrete problems.
   - Recommended additions: Unit 1 direct audience outcome language; Unit 3 avoiding list-only structure; Unit 6 articles/plurals and noun phrases in chart titles/labels; Unit 10 direct but polite first answers; Unit 12 avoiding full-script reading.

5. Increase controlled-to-free scaffolding in Units 7, 9, and 10.
   - Recommended fix: add one controlled matching or sentence-completion step before freer speaking tasks in each of these units.

Unit-specific notes:

- Unit 1: add a Teacher Note about avoiding vague topic statements such as "I will explain about..." and moving toward audience action language.
- Unit 2: add pronunciation/rehearsal instruction after the opening frame: mark pauses after context, message, relevance, and action.
- Unit 3: add a learner-facing warning that an outline is not only a list.
- Unit 4: add spoken drilling after Practice 1 or Practice 2: choose two repaired phrases, mark stress, and say them aloud.
- Unit 5: define `accessibility` before the checklist and add one model of a corrected slide-title article/plural issue.
- Unit 6: add a controlled language table for `approximately/about/around`, `rose/fell by`, and `rose/fell from...to...`; add a Japanese-learner note on chart-title noun phrases and plural marking.
- Unit 7: add a `Key words` box defining `pre-read`, `leave-behind`, `appendix`, `backup file`, `PDF fallback`, and `confidential information`.
- Unit 8: add an explicit "do not memorize a full script" sentence to the speaking task.
- Unit 9: define `asynchronous/async` at first use and add a controlled phrase-practice task before the two-minute speaking task.
- Unit 10: add B1 support before role play and a Japanese-learner note on giving a direct first answer before background.
- Unit 11: add one weak-vs-improved peer-feedback model focused on language feedback.
- Unit 12: define `sanitized data` and add a clear `## Learner deliverable` heading.

Cross-unit language syllabus gaps:

- More repeated pronunciation practice before Unit 8.
- More controlled B1 phrase practice before open speaking in Units 7, 9, and 10.
- More explicit definitions of document/workflow terms.
- More Japanese-learner notes on directness, articles/plurals, noun phrases, and first-answer Q&A behavior.
- More consistent heading and section naming across units.
- A recurring learner-owned English reminder before final production tasks, especially Units 8, 11, and 12.

### Agent 3: Business Presentation Specialist

Read-only review completed. No files edited.

Critical issues:

1. Appendix model dependency is now a release blocker.
   - Units repeatedly refer learners to appendix model sets that do not yet exist in the draft manuscript.
   - Recommended fix: create the six required appendix model stubs before the next substantive unit revision pass, or add temporary in-draft model stubs with stable names, scenario briefs, Q&A pressure points, and unit cross-references.

2. Cross-unit case continuity is weaker than the Plan 3 model system requires.
   - The units are individually coherent, but the recurring cases do not yet feel like a tracked course spine.
   - Recommended fix: add short `Course case connection` boxes in selected units naming the model family explicitly: Process Improvement Briefing, Product/Service/Program Launch, or Project Results Briefing.

3. Final task allows too much drift from business presentation realism.
   - Unit 12 sets the 5-7 minute target and required Q&A, but does not yet require learners to choose an approved business presentation purpose or teacher-approved equivalent.
   - Recommended fix: revise Unit 12 so the final presentation must be a process improvement briefing, product/service/program launch, project results briefing, or teacher-approved equivalent with a clear audience decision, action, or follow-up.

Important improvements:

1. Finance/trading guardrails are strong in teacher notes but need more learner-facing placement.
   - Recommended fix: add short learner-facing sensitive-information checks in Units 6 and 7.

2. Government examples are appropriate, but business-client examples need equal learner-facing visibility.
   - Recommended fix: add paired optional mini-prompts in Units 5-7 and 10.

3. Delivery and contingency guidance is good, but physical room setup needs more concrete treatment.
   - Recommended fix: add 3-5 practical room setup checks to Unit 8 or Unit 11.

4. Q&A is strong, but sector-specific Q&A pressure should be sharper.
   - Recommended fix: add one table of sector-safe Q&A pressure points for finance/trading operations and government administration.

Unit-specific notes:

- Unit 1: add a line in the brief asking whether the presentation is a recommendation, update, launch/explanation, or results briefing.
- Unit 2: add a note that a core message should be testable against the audience's decision or action.
- Unit 3: add one explicit launch purpose to Practice 1 so all three recurring case families appear early.
- Unit 4: add one signposting example for a data limitation or risk.
- Unit 5: add a learner-facing finance/trading dashboard title example, not only an appendix reference.
- Unit 6: add learner-facing finance/trading data guardrails near Practice 4.
- Unit 7: clarify that the 20-minute internal meeting model is a workplace scenario, not the Standard final presentation target.
- Unit 8: add physical room setup checks: stand position, sight lines, note placement, avoiding blocking the screen, and remote participant visibility.
- Unit 9: add one sentence explaining when async is inappropriate.
- Unit 10: add sector-safe Q&A pressure examples for finance/trading operations and government administration.
- Unit 11: add a checklist row for sector/privacy risks before final delivery.
- Unit 12: tighten the final topic requirement so the presentation must be a decision/action workplace presentation, not a generic informational talk.

Cross-unit business and case gaps:

- The six appendix models are essential infrastructure, not optional enhancement.
- Business-client finance/trading contexts are less visible in learner-facing examples than government/administrative contexts.
- The recurring case families need clearer labels in the unit body.
- Final presentation task needs a stronger business-purpose constraint.
- Sector/privacy guardrails should appear before learners create data, visuals, and final materials.
- Physical room setup and hybrid-room practicality need a small expansion.
