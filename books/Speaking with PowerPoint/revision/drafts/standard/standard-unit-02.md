# Unit 2: Message, Objective, and Relevance

An effective presentation is not only a topic with information. It has a message: the main point you want the audience to remember, believe, or act on. When your message is clear, your opening becomes easier to write and your visuals have a purpose.

In this unit, you turn your presentation brief into a core message and a short opening.

## Learning Outcomes

By the end of this unit, you can:

- write a core message as a claim, not only a topic
- connect the message to audience relevance
- draft a short opening that gives context, purpose, and value

## Core Skill: Turn a Topic into a Message

A topic names the area. A message says what you want to communicate about that area.

| Topic | Core message |
|---|---|
| Processing delays | Most delays come from unclear handoffs, so we should test a shared checklist for one month. |
| New support guide | The new guide will reduce repeated questions if staff use it before sending requests to the support team. |
| Project results | The pilot improved response time, but we need one more review before wider rollout. |

A strong core message usually has three parts:

1. a clear claim
2. a reason or evidence direction
3. an action, decision, or implication

This does not mean every message must be long. It means the message should do more than name the subject.

## Presentation English Focus

Use relevance language to show why the audience should listen.

| Function | Useful language |
|---|---|
| Give context | Over the last month, we have seen... / Recently, the team has been dealing with... |
| State the message | My main point is that... / The key message is... / I recommend that we... |
| Explain relevance | This matters for us because... / This affects our ability to... / The impact is... |
| Connect to action | Today, I am asking for... / The decision we need is... / The next step I recommend is... |

For a business audience, avoid an opening that only says, "Today I will talk about..." Add the value or decision.

## Worked Example: From Brief to Opening

Presentation brief:

> I will give a five-minute presentation for a small operations team. The purpose is to recommend a trial workflow change. By the end, the audience should understand why handoff delays are happening and approve a one-month checklist trial. This matters because repeated delays are creating extra work and making deadlines harder to meet.

Core message:

> Most delays come from unclear handoffs, so a shared checklist should reduce repeated work and help the team meet deadlines.

Short opening:

> Over the last month, we have had several delays at the handoff stage of the process. My main point today is that many of these delays are avoidable. I will show where the problem appears, explain why a shared checklist is a practical first step, and ask for approval to test it for one month.

This opening is short, but it gives context, message, structure, and action.

## Practice 2: Use the "So What?" Test

Read each weak message. Ask "So what?" and improve it.

1. I will explain the new workflow.
2. This presentation is about last month's data.
3. We made a new dashboard.
4. I will introduce the project results.

Use these frames if helpful:

- This matters because...
- The audience needs this information so they can...
- My recommendation is...
- The decision we need is...

## Practice 3: Improve a Weak Opening

Weak opening:

> Hello. Today I will talk about the new workflow. First, I will explain the current situation. Next, I will explain the new workflow. Finally, I will explain the schedule.

Improve it by adding:

- one sentence of context
- one clear message
- one relevance statement
- one action or decision

You may use this structure:

> Recently, ___. My main point is that ___. This matters because ___. Today, I will explain ___ and ask for ___.

## AI Critical Literacy: Check a Generic Opening

Sometimes a generated opening sounds smooth but does not fit the real audience. Read this flawed sample.

> Good morning everyone. Today, I am excited to share an innovative solution that will transform our operations and create excellent value for all stakeholders.

Discuss:

1. What is too generic?
2. What information is missing?
3. What could be risky if the presenter has not checked the facts?
4. How can you rewrite it in clear learner-owned English?

Do not use this task to outsource your own opening. The goal is to notice weak language, check responsibility, and write your own message more clearly.

## Bilingual Planning Note

You may plan ideas in the language that helps you think efficiently. However, your assessed message and opening should be drafted, revised, and rehearsed in natural English. Avoid translating sentence by sentence, because the result often sounds indirect or overloaded.

## Speaking Task

Present your opening to a partner in 45-60 seconds.

Use this sequence:

1. Context: Recently, we have...
2. Message: My main point is...
3. Relevance: This matters because...
4. Preview: I will first..., then..., and finally...
5. Action: Today, I am asking for...

Your partner gives feedback using two questions:

- Do I understand the main message?
- Do I understand why this matters to the audience?

## Learner Deliverable

Submit:

- one core message
- one short opening of 4-6 sentences
- one note explaining why the message is relevant to the audience

## Unit Wrap-Up

A strong message helps the audience understand your direction early. It also helps you control what belongs in the presentation. If a detail does not support the message, it may belong in backup material, a follow-up document, or no material at all.
