# Appendix: Slide Design Checklist

Use this checklist when you prepare or revise slides, visual packs, dashboards, charts, or screen-shared materials for a presentation.

## Message and Purpose

| Check | Yes / Not yet | Notes |
|---|---|---|
| The visual has one clear job. |  |  |
| The visual supports what the audience needs to understand, decide, or do. |  |  |
| The slide or visual has one main message. |  |  |
| Extra detail is moved to backup material, an appendix, a pre-read, or a follow-up handout. |  |  |

## Title and Text

| Check | Yes / Not yet | Notes |
|---|---|---|
| The title states the takeaway, not only the topic. |  |  |
| The text is concise and does not become a script. |  |  |
| Labels and short phrases are clear and natural in English. |  |  |
| The spoken explanation adds value beyond the visible text. |  |  |

## Layout and Hierarchy

| Check | Yes / Not yet | Notes |
|---|---|---|
| The most important information is easiest to see first. |  |  |
| Related items are grouped clearly. |  |  |
| Objects are aligned deliberately. |  |  |
| Margins, spacing, and object sizes are consistent. |  |  |
| The slide has enough white space. |  |  |
| The starting point is clear. |  |  |

## Color, Contrast, and Accessibility

| Check | Yes / Not yet | Notes |
|---|---|---|
| Text is readable against the background. |  |  |
| Color has a clear purpose. |  |  |
| Meaning does not depend on color alone. |  |  |
| Color is supported by labels, position, shape, or pattern. |  |  |
| The visual is readable in the real delivery setting. |  |  |
| If the file will be shared, meaningful visuals have alt-text awareness. |  |  |
| If the presentation is recorded, captions or transcript support are considered. |  |  |

## Visual Type

| Purpose | Suitable Visual Type |
|---|---|
| Show a process change | Before/after workflow |
| Show a change over time | Line chart or simple bars |
| Compare two or more items | Bar chart, paired bars, or small table |
| Show a schedule | Timeline |
| Show main issues | Ranked list or simple table |
| Show status at a glance | Dashboard or summary panel |

Before using a complex visual, ask: does this make the point clearer, or only make the slide look more complicated?

## Charts and Evidence

| Check | Yes / Not yet | Notes |
|---|---|---|
| The chart has a takeaway title or clear chart title. |  |  |
| The most important number, trend, or comparison is easy to find. |  |  |
| Labels are readable. |  |  |
| The chart does not use unnecessary colors or categories. |  |  |
| The data source or fictional-data note is included where needed. |  |  |
| Any limitation or caution is prepared for the spoken explanation. |  |  |

## Images, Icons, and Media

| Check | Yes / Not yet | Notes |
|---|---|---|
| Images clarify or support the message. |  |  |
| Images do not feel generic or decorative only. |  |  |
| Important text is not placed over a busy image. |  |  |
| Icons and visual symbols are easy to understand. |  |  |
| Image, template, or media source and license status are acceptable. |  |  |
| No confidential or identifying information is visible. |  |  |

## Style and Consistency

| Check | Yes / Not yet | Notes |
|---|---|---|
| Fonts are consistent. |  |  |
| Colors are consistent. |  |  |
| Line weights, boxes, and icons use a consistent style. |  |  |
| Branding or house style supports clarity instead of dominating the message. |  |  |
| Animation, transitions, audio, or video are used only when they help understanding. |  |  |

## Delivery and Export

| Check | Yes / Not yet | Notes |
|---|---|---|
| The visual works for the delivery mode: in person, online, hybrid, or recorded. |  |  |
| Fonts, charts, media, and links work after export. |  |  |
| A PDF fallback is ready if needed. |  |  |
| The file opens on the actual device or platform. |  |  |
| Sensitive information has been removed or masked. |  |  |

## Final Speaker Check

Prepare a short explanation using these questions:

1. What should the audience notice first?
2. What does the visual show?
3. What is the main point?
4. What detail will you explain aloud instead of putting on the slide?
5. How does the visual support your recommendation, decision request, or next step?

Remember: a good slide or visual supports the presenter. It does not replace the presenter.
