::: {.section-head}
Core Skill: Choose the Structure That Fits the Job
:::

Different workplace purposes need different structures. A simple list is often not enough because it may not show the relationship between points.

::: {.core-skill}
A clear structure helps the audience understand why each point matters, how the points connect, and what they should do next.
:::

::: {.local-head}
Useful Structures
:::

The table below shows several structure choices from the unit.

[table-style: PS Phrase Bank Table]

| Purpose | Useful Structure | Best When You Need To... |
|---|---|---|
| Recommend a change | Problem - cause - solution - action | Explain why change is needed |
| Ask for a decision | Situation - options - criteria - recommendation | Compare choices clearly |
| Report progress | Objective - current status - issue - next step | Update a team or manager |

::: {.practice-head}
Practice Task 1: Match the Structure to the Purpose
:::

::: {.instruction}
Read each situation. Choose the structure that will make the presentation easiest to follow.
:::

1. Explain the current situation.
2. Compare the available options.
3. Recommend one option.
   - Explain the strongest reason.
   - Mention the main risk.
4. Ask for the decision you need.

::: {.speaking-task-head}
Speaking Task: Explain Your Main Message
:::

Use the phrases below to prepare a short spoken explanation.

::: {.useful-language}
Useful language:

- The main issue is...
- The best option is...
- The reason I recommend this is...
:::

::: {.learner-deliverable-head}
Learner Deliverable
:::

By the end of this unit, write a short planning map for a real or realistic presentation from your workplace.

::: {.model-box}
Model:

Today, I will explain why our team should test one shared order-status log for four weeks.
:::

::: {.script}
Good morning. Today, I will explain the problem, show the cause, recommend a short pilot, and ask for one decision.
:::

::: {.tip-box}
Keep the slide simple. Put the detailed explanation in your spoken English, not on the slide.
:::

::: {.caution-box}
Do not include confidential client names, employee names, or unreleased business figures in a classroom presentation.
:::

::: {.ai-literacy}
If you use AI to check your grammar, read the result carefully. Make sure the final language still sounds like your own English.
:::
