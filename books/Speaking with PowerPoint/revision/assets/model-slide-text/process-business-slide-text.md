# Process Improvement Business-Client Deck: Slide Text Plan

Source Model: `process-improvement-briefing-models.md`, Model 1.

Presentation Context: Seika Global Trading Operations, Yokohama Import Documentation Desk. The presenter asks for approval for a four-week pilot using a shared exception log and a fixed 2:15 p.m. handoff checkpoint before the 3:00 p.m. shipping-document preparation cutoff.

Approach: Problem - cause - solution - action. Opens with a concrete incident, not the request. The decision request comes last.

Design Style: Soft card layout. Light background, dark navy text, one muted terracotta accent, rounded panels, generous spacing. Keep all shapes and text editable. Do not use generated text images, stock photography, or decorative clip art.

Capitalization: Slide titles use Title Case. List items and sentences use sentence case.

## Slide 1: A 2:45 p.m. Exception With No Clear Owner

Role: Problem (concrete incident).

On-Slide Composition:

2:45 p.m. Supplier A has not confirmed a packing-list item.

- One person sees the email.
- Another person updates the spreadsheet.
- A third person asks in chat who owns the next action.

3:00 p.m. cutoff in 15 minutes

Key Message Words: `2:45 p.m.`, `no clear owner`, `3:00 p.m. cutoff`.

Emphasis:

- The problem is a missing owner, not careless staff.
- The cutoff makes the timing urgent.

Visual Direction:

- Use a simple clock or time-strip layout, with 2:45 p.m. and the 3:00 p.m. cutoff as the two anchor points.
- Use three small cards for the three people and actions.
- Do not show a decision request on this slide.

## Slide 2: Most Late Handoffs Involve Unclear Notes

Role: Problem (evidence).

On-Slide Composition:

Last month, the team saw:

- 38 late document handoffs
- 61% linked to unclear handoff notes
- 22 minutes average rework time per exception

Note:

- Fictional data for practice

Key Message Words: `61%`, `unclear handoff notes`.

Emphasis:

- The repeated problem is large enough to justify a pilot.
- The evidence supports a limited workflow change, not a full system change.

Visual Direction:

- Use a three-number evidence panel.
- Make `61%` the largest number.
- Keep the fictional-data note small but readable.

## Slide 3: The Cause Is Where the Notes Sit, Not the Number of Checks

Role: Cause.

On-Slide Composition:

The checks stay. The handoff note sits in three places:

1. Email
2. Spreadsheet
3. Handoff message

Result:

- Ownership unclear before the 3:00 p.m. cutoff

Key Message Words: `where the notes sit`, `checks stay`, `ownership unclear`.

Emphasis:

- The cause is note location and timing, not the control checks.
- The checks themselves are not the problem.

Visual Direction:

- Use a three-column current-state layout, with arrows into the result.
- Keep the Supplier A detail off this slide; it appeared on slide 1.

## Slide 4: One Shared Log Makes Ownership Visible Earlier

Role: Solution.

On-Slide Composition:

The pilot changes the handoff point:

- Shared exception log
  - Issue
  - Owner
  - Next action
- Fixed 2:15 p.m. checkpoint
- Control process unchanged

Key Message Words: `shared exception log`, `2:15 p.m.`, `control process unchanged`.

Emphasis:

- The recommendation changes where and when ownership is confirmed.
- The control process does not change. Give this line the same visual weight as the other two.

Visual Direction:

- Use a before/after workflow layout. Current side: scattered notes. Pilot side: shared log plus checkpoint.
- Do not make the log look like a dense spreadsheet.

## Slide 5: The Pilot Is Short, Owned, and Measurable

Role: Plan.

On-Slide Composition:

Pilot schedule:

1. Week 0
   - Control review of log fields
2. Weeks 1-4
   - Daily 2:15 p.m. checkpoint
3. End review
   - Late document handoffs
   - Average rework time
   - Ownership feedback

Target:

- 25% fewer late document handoffs

Key Message Words: `short`, `owned`, `measurable`, `25% fewer`.

Emphasis:

- The pilot has an owner and review measures.
- The target is a test point, not a promise.

Visual Direction:

- Use a timeline layout with numbered chronology.
- Add the target as a small callout, not the dominant message.

## Slide 6: Approve the Pilot and Confirm Ownership

Role: Action (decision request).

On-Slide Composition:

If we agree today, we can start next Monday:

1. Approve the four-week pilot.
2. Confirm the documentation lead as checkpoint owner.
3. Review late handoffs and rework time at the end of the pilot.

Key Message Words: `approve`, `documentation lead`, `next Monday`.

Emphasis:

- The close returns to the exact decision.
- The next action is immediate and practical.

Visual Direction:

- Use a decision-summary layout with a numbered list.
- Do not introduce new evidence on this slide.
