## Core Recurring Terms

Terms that should recur through the book for reinforcement. Set from Part 1; extend as later Parts are drafted:

**central bank, regulator, supervision, consumer protection, payment system, cross-border, financial system, risk.**

**Known limitation (Parts 1–4):** Book A's Part 1 topics (crypto regulation, CBDCs, fintech regulation, data privacy, financial inclusion) are only loosely connected, so genuine term carry-over between consecutive Part-1 topics is thin. Several topics have only 1–3 recycled terms, all drawn from the core-recurring set rather than from the immediately preceding topic. Part 2 (market volatility, credit ratings, insurance, stress testing, sovereign debt) is more cohesive around financial-stability vocabulary, but carry-over from Part 1 is still modest: the Part-2 opener 2.1 recycles only 3 terms (regulator, exchange, market), all from the core-recurring set, because a circuit-breaker mechanics piece shares little settled vocabulary with the Part 1 topics. Part 3 (green finance, infrastructure, trade/tariffs, pension reform, post-COVID recovery) and Part 4 (AML, financial literacy, wealth inequality, corporate governance, economic diplomacy) are self-contained policy pieces with even thinner carry-over from the earlier Parts; recycled lists for these run 3–4 terms and lean on the core-recurring set (capital, risk, cross-border, regulator, government bond) plus a few genuinely shared terms from the same Part. Recycled lists are set to terms that genuinely appear in each Reading, not padded to a target count. Flagged for the Phase-1 Part-grouping review.

**Accepted exception to the 3–5 recycled-term floor (2026-09-12, `qa-todo.md` item 5):** topic 1.2 (Central Bank Digital Currencies) recycles only 2 terms (*central bank, stablecoin*). It is the book's second topic, so its only possible source is 1.1 (Cryptocurrency Regulation), whose term set (cryptocurrency, blockchain, crypto exchange, stablecoin, issuer, supervision) has almost no genuine overlap with 1.2's CBDC-mechanics content beyond the one term already recycled. Forcing a third term from that list into the prose would be artificial rather than a real recycling. User-approved decision: leave 1.2 at 2 recycled terms as a documented exception rather than pad the text; do not treat this as an unresolved defect in future audits. (Topic 1.5's equivalent gap was fixed instead, since it had a genuine four-topic pool to draw from — added "regulator", now at 3 recycled terms.)
