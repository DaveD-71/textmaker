# Let's Talk Finance — Shared Term Bank

Aligned plain-English definitions for finance terms that recur across **both** books.
When a term appears in a Reading in either book, its glossary entry in that book must be
consistent with the wording here (not necessarily identical prose, but the same meaning,
scope, and B1+/B2 register). Populated as drafting proceeds.

Each entry: **Term.** One-sentence plain definition. Then why it matters / how it comes up.
No `[Part.Topic]` tags here — those live in each book's own `glossary.md`.
